# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/wedding-invitation.git
```

### Open the Project

```bash
cd wedding-invitation
```

Run the project using **VS Code Live Server**, or simply open:

```text
index.html
```

---

# 💌 RSVP System

The RSVP page is connected to **Google Apps Script**.

Guests can:

- Confirm attendance
- Enter the number of guests
- Leave wishes or notes
- Submit responses directly to Google Sheets

Update your Apps Script URL in **script.js**.

```javascript
const scriptURL = "YOUR_GOOGLE_APPS_SCRIPT_URL";
```
